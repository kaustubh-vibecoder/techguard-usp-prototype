Engineering Architecture · TechGuard USP

Reference Architecture — Unified Service Platform

Three-layer Salesforce-native stack with explicit data and action flows. Personas at the top, source systems at the bottom, cross-cutting trust + observability on the right rail.

v1.0 · Jun 2026
Built on Agentforce · Data Cloud · MuleSoft · Slack
🟦 Surfaces
Where humans + agents meet. Salesforce-native. No parallel customer portal.
🟧 Agentforce Runtime
Planner / RAG / Actions / Policy — independently swappable. Policy is the safety bar.
🟩 Data Cloud · Endpoint Graph
The moat. Identity-resolved, tenant-isolated, zero-copy. 2M endpoints unified.
🟪 Ingest & Orchestration
MuleSoft + Streaming + Kafka. Telemetry up, actions down, both tenant-aware.
Design principle #1
Separation of concerns inside the runtime.
Planner = creative. Actions = deterministic. Policy = independent. Swap any layer without rewriting the others.
Design principle #2
The Endpoint Graph is the moat.
Identity-resolved unified data is a 6-mo build for us; a multi-year build for ServiceNow / Workday. The substrate is the durable advantage.
Design principle #3
Trust scales with autonomy.
Blast-radius classifier + per-tenant Trust Dial + eval-as-CI. Autonomy without these isn't speed — it's blast radius.
